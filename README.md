# MediOS - Pharmacy Management System

Cross-platform pharmacy management system built with Flutter.

## Platforms
- Android
- iOS
- Web
- Windows

## Features
- Inventory Management
- Sales & Billing
- Supplier Management
- Customer Management
- User Authentication & Roles
- Dashboard & Reports

## Getting Started

1. Install Flutter SDK (>=3.0.0)
2. Run `flutter pub get`
3. Run `flutter run` for your target platform
